第 6 章　　社会网络分析

学习目标：完成本章后，你应能
（1）用节点与边表示一批人物/机构关系；
（2）解释度中心性、介数中心性各自回答什么问题；
（3）用社群发现识别凝聚子群；
（4）指出网络分析自身可能放大的偏见。

6.0 思政导入

思政融入（课程思政）：从师承、交游与民族交往的网络中，常能看到中华民族交往交流交融的历史脉络。用社会网络方法呈现这种“多元一体”的联结，既是对历史的尊重，也有助于今天中华民族共同体意识的培育——方法服务于对团结与统一的深刻理解。

思政案例（课程思政示范案例 / AI 思政课 知识库）：可参照《数据结构与算法》课程思政以“队列”类比抗疫秩序的案例——方法的有序，映射着社会对公平与共同体的追求。

导学

6.1 关系即数据

第 2 章把"关系类"数据单列，因为它回答的是"谁和谁连在一起"——这是单条记录答不了的。家谱、师承、交游、引文、书信往来，本质都是网络。但关系不是从数据表里自然长出来的：研究者必须先规定什么算"交游"（同席、互通信件、互相引用，还是仅在同一文本中出现），再说明每条关系由哪种史料支持。

关系类型 / 经典案例研究目的数据来源数据表现形式
家谱：佛罗伦萨美第奇家族的崛起
Padgett 与 Ansell，Robust Action and the Rise of the Medici, 1400–1434（1993）		解释美第奇为何能在佛罗伦萨不同派系之间取得政治地位，考察婚姻、经济与庇护关系的多重嵌入，而非只用人物传记说明权力来源。1400—1434 年佛罗伦萨税册、婚姻档案、贷款与商业记录、政治派系及庇护材料；研究者将资料整理为约 92 个精英家族及其关系。节点为家族；婚姻、贸易、贷款、庇护等分层为不同类型的边。以多重网络、块模型和家族联结图比较“同一节点连接于不同网络”所形成的政治位置。
师承：哲学思想的代际链条
Randall Collins，The Sociology of Philosophies（1998）		比较中国、古希腊、印度、伊斯兰世界与欧洲等思想传统，解释哲学流派如何在师徒、论争与“注意力空间”中形成和衰落。哲学史著作、人物传记、学校与讲学记录、著作引用及思想争论材料；把跨世纪的人物关系整理成思想谱系。节点为思想家，边为师承、影响、争论或门派联系，必要时加入年代。以跨时间的有向关系图、流派分叉与长链呈现知识传承和学派分化。
交游：弱关系与求职机会
Mark Granovetter，The Strength of Weak Ties（1973）		检验为什么较少互动的熟人关系有时比亲密朋友更能连接不同社交圈，并为求职者带来新信息与机会。求职者访谈与问卷，记录求职者与提供岗位信息者的身份、既有联系及见面频率，区分亲密朋友、普通熟人等关系。节点为求职者及其联系人；边按“经常、偶尔、很少”联系划分强度，形成个人中心网络。图中可用边粗细表示互动频率，用桥梁位置说明信息跨群体传播。
引文：科学论文网络
Derek J. de Solla Price，Networks of Scientific Papers（1965）		研究科学文献如何积累、何以形成可识别的研究前沿，并检验引文为何呈现集中分布以及对较早论文的选择性回溯。期刊论文及其参考文献，按发表年份、引用次数和被引文献年龄建立统计与网络样本；后来研究也以大型引文索引扩展这种方法。节点为论文或作者；“A 引用 B”是一条从新文献指向旧文献的有向、按时序排列的边。可用引文图、入度分布、共被引矩阵与时间层图呈现研究前沿和知识谱系。
书信往来：早期近代“文人共和国”
斯坦福大学 Mapping the Republic of Letters（2008 年起）		重建欧洲学者跨地域、跨语言的知识交流网络，追问思想、人物与书籍如何沿通信线路传播，以及哪些节点连接不同城市和学术圈。伏尔泰、富兰克林、Erasmus 等人物的书信目录、寄收人、日期、地点与馆藏档案；相关子项目亦整合书信内容、共同引用及地理信息。节点为寄信人、收信人或地点；边记录通信，方向为寄—收，权重可用信件数表示，时间可切片。常以社会网络图、地理流向图、时间轴与共引网络联合呈现。

阅读这张表的关键：同样叫“关系”，家谱重在亲缘边，师承重在有向影响，交游需说明互动强度，引文天然具有方向和时间顺序，书信则同时携带寄收人、地点与日期。转换前必须明确关系定义；不要把五类材料直接合并成一张“谁和谁有关”的泛化网络。

真实案例：19 世纪波兰科学家在拉丁美洲的跨国网络。 Kaye（2024）从一张 1874 年利马合影出发，结合迁移者的书信、出版物及共同出现的报刊记录，重建波兰科学专业人士在秘鲁及更广地域中的联系。这个案例把照片、文本和人物传记放在同一证据链里；它也提醒我们，照片中的九人并不等于网络中的全部成员。

理论

6.2 图的语言：节点、边、度、路径

  • 节点（node）：一个人、一本书、一个机构；
  • 边（edge）：两者间有定义的关系（师—徒、引—被引、寄—信）。有方向的引用边与无方向的共同署名边不能混为一谈；
  • 度（degree）：一个节点连接的边数；加权网络还可计算加权度，但"联系多"不等于"历史影响大"；
  • 路径：两节点间依规则连接的路线。最短路径依赖关系是否有向、边权如何解释，以及网络是否缺失。

实际建网时要声明节点唯一标识、边的方向、时间范围、关系类型和证据来源。若"甲给乙写信"与"甲乙同见于一篇记载"都压成同一种边，图就会隐藏证据强弱与含义差异。

理论

6.3 中心性：谁是关键节点

  • 度中心性：直接邻居数量，可描述直接联系的广度；孤立节点、资料覆盖量和关系定义都会影响排名。
  • 介数中心性：节点处在多少对其他节点的最短路径上，可提示结构桥接位置；它不证明此人有意"控制"信息。
  • 接近中心性：到其他可达节点的平均最短距离；网络断开时需说明算法如何处理不可达节点，或改用调和中心性。

三种中心性常不一致：一个"朋友多"的人未必是"桥梁"。研究者应先把"关键"翻译成可检验的问题，再选择指标，并与传记、文本记录或人工抽样交叉核对。中心性是特定网络和口径下的结构描述，不是人物价值榜。

理论

6.4 社群发现：凝聚子群

社群发现算法尝试把"内部连接相对密、外部连接相对疏"的节点聚成一团。常见方法包括模块度优化和 Leiden/Louvain 等算法，但结果会随边的定义、分辨率参数、随机种子和样本范围改变；输出社群不能自动等同于真实历史派别。

经典参照：Zachary 空手道俱乐部网络。 这份由真实社团互动记录构成的小型网络，常用于说明网络分裂、社群划分与算法比较。它是一个特定社团的经典基准，不应被当作所有社会网络都会清楚分成几团的证明。

近年数字人文研究更强调网络的情境与不确定性：Kaye（2024）讨论如何用社会网络和数字工具从跨国迁移材料拼接历史"大图景"；Conroy 等（2024）则提出在人文网络图中表达关系确定程度的方式。二者共同提醒我们：社群图需要同时展示证据覆盖和不确定性，而不只展示颜色分组。

理论

6.5 文本 × 网络：从共现到引文

网络常由文本而来：同一篇文章共现的词可组成词网；互相引用的文献构成引文网；信件中可确认的寄收关系构成人物网络。第 4 章的命名实体识别可以提供候选人物，但"同一段落出现"只是共现，不等于两人相识或有直接关系。

因此要保留从图到原文的回溯：每条边附上来源、页码/段落、日期、抽取方法及置信度；对自动抽取的关系做人工抽查，并比较不同共现窗口或关系阈值下的网络变化。把文本证据转成关系时，需区分作者原文、编者注和后人研究。

理论

6.6 伦理坐标：网络也会偏见（本章核心能力）

  • 抽样偏差：被数字化、被研究得多的人物更"中心"，沉默者天然边缘；
  • 缺失关系：信件散佚、著者不详，会让真实枢纽"消失"；
  • 关系不确定：同名消歧错误、间接转述或资料日期不明，都会把猜测画成确定连线；
  • 被代表：用"中心性高"暗示"更重要"，是把结构当价值；网络边界也可能排除不符合既定定义的人和群体。

近三年研究证据：Conroy 等在 Frontiers in Communication（2024）讨论如何将模糊、概率性的人文资料呈现在网络可视化中，提出把不确定性编码进连线或节点标记。Kaye 在 BJHS Themes（2024）以波兰科学专业人士的迁移网络为例，展示如何综合照片、书信与出版物，同时处理局部史料与跨国"大图景"之间的尺度问题：Kaye, 2024；Conroy et al., 2024。

一条红线：不把"网络中心"直接等同于"历史重要"；呈现中心性时同步说明数据覆盖的局限。

6.7 综合实践：构建关系网络并分析关键节点

任务一：从材料建立人物关系网

小练习 6.1（网络分析）：取第4章 NER 抽出的人物—地点 / 人物—人物关系，回到原文核实后，用 networkx 建一张小网。本章 V2.2 的《基于用户关系管理的高校图书馆数字学术服务重塑》《基于开源情报的军事知识图谱问答智能服务研究》展示了"关系数据→服务 / 问答"的落地，可对照思考你所建网络的用途。

任务二：比较中心性并解释“关键人物”

  • 目标：在任务一建好的人物关系网上，量化谁最核心。
  • 步骤：
    1. 用 networkx 计算 degree / betweenness / closeness；
    2. 排序取 Top 5；
    3. 检查“度数最高”是否等于“最关键”，举一个反例；
    4. 做社群发现（community detection）；
    5. 写 150 字结论。
  • 工具：networkx。
  • 产出：中心性排序表 + 社群划分 + 结论。
  • 评价量规：三种中心性正确（40%）、反例有见地（30%）、结论清晰（30%）。

任务三：用“完全图”检验“普遍联系”

  • 研究命题：高中政治提出“事物是普遍联系的”，管理学的“强迫联系法”要求把看似无关的对象主动组合，寻找新的关联。以全班同学为节点，建立密度为 100% 的无向网络，检验“可以建立联系”与“证据足以支持联系”是否是同一回事。
  • 节点与边界：以课堂分组名单和当日到课名单为准，先消除重复记录并用学号或匿名编号区分同名者；一人对应一个节点。区分两层边：课堂访谈层必须覆盖全部配对；实质关联层只记录双方确认、可核查的联系。只记录课程学习、兴趣、能力、资料和观点层面的公开信息，不采集家庭住址、健康、私人关系等敏感数据。
  • 完成条件：若有效节点数为 n，每位同学均须与其他 n−1 人完成一次访谈；总边数必须为 n × (n−1) / 2。因此每个节点度为 n−1，无向简单图密度为 1。采用循环配对制分轮进行：每轮同时开展约 n/2 组对话，共 n 或 n−1 轮即可覆盖全部配对；每轮两分钟，必要时分两次课完成。缺少任意一对，均不能称“100% 密度”。
  • 强迫联系规则：每对同学用“共同点—差异点—桥梁”访谈：① 找出一个真实、可核实的共同兴趣、课程经历或协作需求；② 找出一个能力、方法或观点差异；③ 用一条桥梁把二者连接起来，例如“A 提供资料，B 提供方法”“A 的观点补充 B 的反例”或“二人引用同一文本作不同论证”。
  • 异质性约束：不得把“同班同学”或“都参加过本课程”包装成全部边的统一含义。每条基础边必须填写方向、关系类型、主题、共同点、差异点、桥梁、来源/确认方式；全班优先分配当前最少出现的关系类型，尽量使不同类型均衡。若访谈结束后双方仍未发现实质关联，则访谈层保留一条边、实质关联层标为“未证实”，不得把推测写成关系。
  • 有向与无向：合作、同乡、同学、同门等可对称往返的关系，一般记为无向边；引用—被引用、推荐—被推荐、提供—获得资料、传播—接收观点等含有来源、去向或先后次序的关系，记为 A→B 等有向边。为使课堂密度计算有统一口径，100% 完全图只指无向的“已访谈”层；有向关系作为另一张图单独计算出度、入度和有向密度，禁止直接混入无向密度。
  • 工具建议：绘图与验证推荐使用 NetworkX 或 Gephi。NetworkX 适合检验节点、配对、缺边、密度、中心性和导出统计结果；Gephi 适合导入节点/边表，按方向、类型、权重过滤并调整布局。二者均须保留原始 CSV 或 GEXF/GraphML，避免仅提交视觉化截图。
阶段 / 对应内容具体操作提交证据
① 定义节点与关系
6.1—6.2		统一节点 ID、边定义与数据字典。将关系限定为“课程资源、兴趣、能力、观点、协作、传播”六类，每条边选择一个主类型；区分有向的信息流与无向的共同参与。节点表、边属性字典、匿名编号规则、完整的“什么算一条边”说明。
② 采集异质关系
6.1—6.2、6.5		完成“共同点—差异点—桥梁”访谈。每对同学建立一条基础边，并记录一句可复核短证据；来自文本、选题或消息的关系，应保留标题、段落/位置与日期。另用 direction 标记无向、有向或有向互惠。边表字段：source,target,direction,type,topic,commonality,difference,bridge,evidence,confirmed；同时提交缺失配对清单。
③ 验证完全图与路径
6.2—6.3		用 NetworkX 检查自环、重复边和缺边，计算 number_of_edges()、density() 与 degree()；导入 Gephi 进行布局核对。分别比较无向 graph 与有向 DiGraph 的中心性，不能把入度与度中心性混为一谈。访谈层密度为 1、缺边数为 0；无向度及有向出度/入度表；Gephi 或 NetworkX 图形，以及结构指标失去区分力的说明。
④ 按关系属性分析社群
6.4—6.5		结构完全图无法仅凭连接有无区分社群，因此分别按六类边、主题相似度或来源类型过滤、赋权或分层；只保留访谈/文本支持的属性，不根据相邻节点推造关系。至少两张按关系类型过滤的子图、社群划分、参数说明，以及与现实小组重合情况的比较。
⑤ 反思联系、异质与偏见
6.1—6.5 + 伦理		说明 100% 密度来自课堂任务设计，不代表全员关系亲密或影响力相同；检查主动表态、记录详略、默认关系类型造成的偏差，并互相核对确认结果。隐私与偏差检查表、至少三条数据修改记录、150 字结论。

示例：匿名编号 S03—S17 的主关系类型为“课程资源”，共同点是都研究宋代材料，差异点是 S03 更关注人物年表而 S17 更关注传抄谱系，桥梁是“用前者的时间轴核对后者的师承关系”。证据字段注明双方确认及资料名称。不要只写“二人都喜欢数字人文”，因为这种边不能复核。

讨论：完全图让每个人在结构上彼此可达，却不代表联系同质、同等重要或真实稳定。请回答：⑴ 联系是否因任务机制被“强迫生成”；⑵ 异质信息为何藏在边属性而不只是节点数或边数中；⑶ “普遍联系”如何转化为可操作、可证伪且有边界的数据问题。评价量规：结构与密度验收（25%）、关系证据可核查（25%）、异质关系设计与类型平衡（25%）、中心性/社群解释（15%）、隐私与偏差反思（10%）。

理论

6.8 本章小结与思考

带走三件事：图的语言（节点/边/度/路径）、三种中心性（度/介数/接近，答不同问题）、社群发现 + 偏见自觉。网络让你看见"结构"，但结构不等于价值。

思考题

  1. 用你专业的某组关系（师承/合作/引用）画成网络，谁的中心性最高？这和你既有认知一致吗？
  2. "被数字化得多"的人更中心——这会怎样扭曲我们对历史圈子的理解？
  3. 如果一封关键信件散佚，网络分析的结论会怎样改变？这提醒我们什么？

课堂复现（检索即方法）：下列代码直接调用 OpenAlex 免费 API 复现本章文献检索（无需密钥）。

import urllib.request, urllib.parse, json
q = 'data science digital humanities'
url = 'https://api.openalex.org/works?search=' + urllib.parse.quote(q) + '&per_page=10&sort=cited_by_count:desc'
oa = json.loads(urllib.request.urlopen(url, timeout=30).read())
for w in oa['results']:
    print(w['publication_year'], w['title'], '->', (w.get('primary_location') or {}).get('source', {}).get('display_name'))
